# Wispwood

Hold the lantern. Outlast the night.

A twin-stick autumn-forest survival game: Ember, Ice, Bolt, Void, a fortune wheel that invents spells, gold upgrades, and a gold-run mode.

- **wispRelic:** https://j6sistek-ui.github.io/Wispwood/relic/

Click those. They open the live game in your browser.

## Run locally

```bash
npm ci
npm run dev
```

Then open the preview. `WASD` move, click to shoot, `B` opens the spellbook.

## Modes

- **Enter the clearing** — normal run, start with 0 gold
- **Sand box clearing** — same game, start with 99999 gold
